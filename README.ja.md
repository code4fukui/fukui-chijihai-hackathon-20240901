# fukui-chijihai-hackathon-20240901

このリポジトリは、**福井県知事杯ハッカソン2024**用のものです。本イベントは、参加者が自治体と協力して、福井県の地域課題に対するオープンソースのソリューションを提案・開発するシビックテックイベントです。

## イベントレポート

Day 1（2024年9月28日）のレポートが公開されており、自治体による課題プレゼンテーション、チームでのアイディア出し、初心者対象講座の様子をご覧いただけます。

- **[Day 1のレポートを見る](report/index.html)**

## 2024年の課題

今年のハッカソンでは、以下の2つの自治体から提示された課題に取り組みます。

- **敦賀市: 空き家の利活用**
  - **目標:** 所有者が空き家を売却または賃貸するよう後押しし、空き家を活用したい人が利用できる仕組みを構築すること。既存の「空き家情報バンク」は登録者が少なく、市は新たな解決策を求めています。

- **鯖江市: 市民の声を政策に反映させるデジタル・プラットフォームの整備**
  - **目標:** 政策立案に市民の声をより反映させるためのデジタル・プラットフォームを開発すること。市民の参加・協働を促進し、市民が主体となって社会課題への解決策を自ら提案し実行する文化を育むことを目指します。

## 特徴

- 敦賀市および鯖江市の職員と直接協働できます。
- ソリューションは自治体での社会実装を目指し、オープンソースソフトウェアとして開発されます。
- 開発期間中は有識者による技術的アドバイスが提供されます。
- Day 1の午前中に、Webアプリ開発とシビックテックに関する実践的な**初心者対象講座**が開催されます。

## 参加方法

1. [応募要項](https://code4fukui.github.io/fukui-chijihai-hackathon-20240901/appreq.html)を確認してください。
2. 締切までに[公式フォーム](https://code4fukui.github.io/fukui-chijihai-hackathon-20240901/)から参加登録を行ってください。
3. イベントに参加し、チームと協力してソリューションを構築してください。

個人およびチームでの参加が可能です。開発されたすべてのサービスやプロダクトは、オープンソースソフトウェアとして福井県に提供していただきます。
